# 详细设计方案模板

## 用途

本文件用于承接 `prd-maker` 中阶段三的“第六步：模块和页面下钻”说明。

## 何时读取

优先在以下情况读取本文件：

- 已明确进入阶段三，需要展开 `6. 详细设计方案`
- 需要对功能清单中的某个模块、页面或功能点做逐项详细设计
- 需要补充详细设计正文模板
- 需要补充附录中的页面规格说明

以下情况不优先读取本文件：

- 只是在阶段一或阶段二整理章节骨架
- 只需要确定阶段三的高层章节结构
- 只需要做 PRD review 或补漏检查

适用于以下场景：

- 阶段三详细方案中的模块展开
- 阶段三详细方案中的页面展开
- 对功能清单中的某个模块、页面或功能点做逐项详细设计

## 模块和页面下钻

当进入阶段三、需要制作详细方案时，按页面或模块展开：

- 页面/模块名称
- 页面/模块描述（包含页面/模块目标、适用角色、优先级）
- 输入/前置条件
- 需求描述（操作/交互/状态变化说明等）
- 输出/后置条件
- 权限控制
- 依赖与备注（可按需补充埋点/日志要求）

无原型时，用功能语言描述页面，不强行写视觉细节。

如果当前 PRD 已进入具体功能模块细化阶段，默认要求这一段设计本身写到可验收：

- 需求描述要写清触发条件、操作过程、交互反馈和状态变化
- 输出/后置条件要写清操作结果、结果落点和后续影响
- 权限控制要写清谁能做、谁不能做
- 如存在关键限制条件，应在对应模块后补充字段说明、校验规则和异常提示

除非用户明确要求单独整理测试或验收清单，否则不要在每个模块后重复追加一段结构相似的验收说明。

## 附录：页面规格

当阶段三的 `6. 详细设计方案` 需要继续补充页面级细节时，可在附录中补充页面规格说明。

页面规格建议作为详细设计方案的补充材料，优先补以下内容：

1. 字段说明
2. 校验规则
3. 异常提示

补充要求：

- 附录内容应服务于正文中的详细设计方案，不单独替代正文结构
- 只有在正文不足以支撑研发、设计、测试理解时，再补字段说明、校验规则和异常提示
- 不要把已经写过的操作结果、权限限制、状态变化原样再抄一遍
- 如果用户额外要求测试清单或验收清单，再单独补充集中式验收标准
