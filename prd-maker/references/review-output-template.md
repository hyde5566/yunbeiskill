# PRD Review 输出模板

## 用途

本文件用于承接 `prd-maker` 中的 PRD Review 输出结构说明。

## 何时读取

优先在以下情况读取本文件：

- 用户明确要求 review 现有 PRD
- 需要输出缺漏分析、风险点和修改建议
- 需要整理评审意见的输出结构

以下情况不优先读取本文件：

- 用户要新建阶段一、阶段二或阶段三文档
- 只是补充正文章节，而不是做 review
- 只需要检查文档质量维度，此时可优先配合 `references/prd-checklist.md`

适用于以下场景：

- Review 现有 PRD
- 对需求文档做缺漏分析
- 输出评审意见和修改建议

## PRD Review 输出标准

Review 现有 PRD 时，优先按以下结构输出：

- 已明确项
- 缺失项
- 模糊项
- 冲突项
- 风险点
- 待确认项
- 修改建议

必要时增加优先级：

- P0：阻塞评审 / 阻塞开发 / 阻塞测试
- P1：重要问题，可能导致返工
- P2：优化项，提升清晰度
