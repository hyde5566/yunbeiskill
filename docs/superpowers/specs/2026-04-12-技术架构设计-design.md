## 1. 设计背景

基于《云贝Skill管理系统-需求文档 v1.8》，进行技术架构设计。

**核心需求：**
- Skill入库管理（提交、审核、入库、发布）
- Skill版本管理（版本记录、更新通知、历史版本下载）
- Skill检索中心（搜索、分类筛选、详情查看、Zip包下载）
- Skill评分反馈（员工评分、使用反馈）
- 项目管理（项目列表、项目成员管理）
- 组织部门管理（部门层级、员工账号）
- 系统管理（权限配置、操作日志、登录日志）
- 统计管理（多维度统计、数据导出）

## 2. 技术选型

### 2.1 整体技术栈

| 层级 | 技术方案 | 选型理由 |
| --- | --- | --- |
| **前端** | Vue3 + Ant Design Vue + Pinia + Axios + Vite | Vue生态成熟，Ant Design Vue组件丰富，适合企业级后台 |
| **后端** | NestJS + TypeScript | Node.js企业级框架，前后端统一语言，模块化架构清晰 |
| **数据库** | MySQL 8.0 | 本地已安装，成熟稳定，关系型数据库适合业务数据 |
| **文件存储** | 阿里云OSS | 无限容量，签名URL安全下载，成本可控 |
| **部署平台** | 阿里云 | 国内主流云平台，产品线完整 |
| **用户认证** | 系统独立登录（账号密码 + JWT） | 简单快速，无需对接企业SSO |

### 2.2 架构模式

**四层分层架构，前后端分离：**

```
客户端层（浏览器）
    ↓ HTTPS
前端层（Vue3 SPA → OSS/CDN）
    ↓ RESTful API
后端层（NestJS → ECS）
    ↓
数据层（MySQL + OSS）
```

## 4. 后端架构设计

### 4.1 NestJS模块划分

| 模块 | 职责 |
| --- | --- |
| 认证模块 | 登录、登出、密码修改、JWT验证 |
| Skill模块 | Skill入库、版本管理、分类管理、可见范围 |
| 审核模块 | 审核流程、分配审核员、审核记录 |
| 用户模块 | 账号管理、权限配置 |
| 部门模块 | 部门层级管理 |
| 项目模块 | 项目列表、项目成员管理 |
| 下载模块 | 下载记录追踪 |
| 评分模块 | 评分、反馈管理 |
| 通知模块 | 站内通知、版本更新提醒 |
| 统计模块 | 多维度统计、数据导出 |
| 文件模块 | OSS上传、签名URL下载 |
| 日志模块 | 操作日志、登录日志 |

### 4.2 权限控制设计

**三种权限可自由组合配置：**

| 权限类型 | 代码 | 包含能力 |
| --- | --- | --- |
| 基础权限 | basic | 搜索、下载、提交、评分反馈 |
| 审核权限 | review | 审核流程操作、批准/驳回 |
| 管理权限 | admin | 系统管理、全局统计、导出 |

**常见角色配置：**
- 普通员工 = 基础权限
- 审核员 = 基础权限 + 审核权限
- 管理员 = 基础权限 + 审核权限 + 管理权限

### 4.3 API设计规范

采用RESTful风格，统一响应格式：

```
成功响应：
{
  "code": 0,
  "message": "success",
  "data": {...},
  "timestamp": 1706000000
}

分页响应：
{
  "code": 0,
  "data": {
    "list": [...],
    "pagination": { "page": 1, "pageSize": 20, "total": 100 }
  }
}
```

**核心API示例：**

| 功能 | API |
| --- | --- |
| 登录 | POST /auth/login |
| Skill列表 | GET /skills |
| Skill详情 | GET /skills/:id |
| 提交Skill | POST /skills/submit |
| 获取下载链接 | GET /skills/:id/versions/:vid/download-url |
| 审核通过 | POST /reviews/:id/approve |

### 5.1 核心表清单

**共19张表，按业务分组：**

| 分组 | 表名 | 用途 |
| --- | --- | --- |

### 5.2 关键字段设计

**Skill状态枚举：**
- pending_review（待审核）
- reviewing（审核中）
- approved（已入库）
- published（已发布）
- taken_down（已下架）

**可见范围类型：**
- all（全部可见）
- project_members（按项目成员可见）
- specific_accounts（指定账号可见）

## 6. 部署方案

### 6.1 云资源清单

| 资源 | 规格 | 用途 | 月费用估算 |
| --- | --- | --- | --- |
| ECS云服务器 | 2核4G | NestJS后端 | ~100元 |
| RDS MySQL | 2核4G，50GB | 业务数据库 | ~200元 |
| OSS对象存储 | 标准存储 | Zip包存储 | ~20元起 |
| 域名 + SSL证书 | — | HTTPS访问 | SSL免费，域名~50元 |
| **合计** | — | — | **~370元/月** |

### 6.2 部署架构

```
用户访问 skill.yunbei.com
    ↓ HTTPS
前端静态文件（Vue3 → OSS + CDN）
    ↓ API请求
ECS云服务器（NestJS）
    ↓ 内网通信
RDS MySQL + OSS（数据存储）
```

### 6.3 安全配置要点

- **VPC专有网络**：ECS和RDS在同一VPC，内网互通
- **网络安全组**：ECS仅开放443端口，数据库仅内网访问
- **SSL证书**：全站HTTPS
- **OSS私有Bucket**：Zip包不公开，通过签名URL下载（有效期1小时）

## 7. 关键技术决策

### 7.1 Zip包存储方案

采用阿里云OSS存储：
- 上传时校验文件大小（50MB上限）
- 存储路径按Skill唯一标识分目录
- 下载通过后端生成签名URL，前端调用OSS下载

### 7.2 站内通知实现

数据库存储通知记录：
- 版本更新通知：新版本发布时通知已下载用户
- 审核分配通知：审核员被分配任务时通知
- 前端轮询获取未读数量（每30秒），无需WebSocket

### 7.3 下载追踪方案

每次下载记录完整信息：
- 下载人、下载时间、所属部门、Skill版本
- 用户可查看历史下载列表
- 管理员可查看全局下载统计
