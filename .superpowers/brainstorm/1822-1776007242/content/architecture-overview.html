整体架构概览

四层分层架构，前后端分离

客户端层
浏览器访问
↓ HTTPS
前端层
Vue3 + Ant Design Vue + Pinia + Axios
职责：UI渲染、路由管理、状态管理、API调用
↓ RESTful API (JSON)
后端层
NestJS + TypeScript
职责：业务逻辑、权限校验、文件处理、日志记录
↓
MySQL 8.0
业务数据存储
阿里云 OSS
Zip包存储

设计要点

  • 前端部署在 OSS/CDN，静态资源加速
  • 后端部署在 ECS 单实例，成本可控
  • MySQL 部署在 RDS 或同 ECS 内
  • OSS 私有 Bucket，签名 URL 安全下载
