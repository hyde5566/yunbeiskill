前端架构设计

Vue3 + Ant Design Vue + Pinia + Axios

项目目录结构

yunbei-skill-web/
├── src/
│   ├── api/          # API封装层（Axios实例 + 各模块API）
│   ├── assets/       # 静态资源（CSS/图片）
│   ├── components/   # 公共组件
│   │   ├── layout/   # 布局组件（AppLayout/Sidebar/Header）
│   │   ├── common/   # 通用组件（SearchBar/Pagination/UploadZip）
│   │   └── business/ # 业务组件（SkillCard/ReviewForm）
│   ├── pages/        # 页面组件（按模块划分）
│   │   ├── auth/     # 登录/修改密码
│   │   ├── skill/    # 检索中心/详情/提交/下载记录
│   │   ├── review/   # 待审核列表/审核详情（审核权限）
│   │   ├── admin/    # 用户/部门/权限配置（管理权限）
│   │   ├── stats/    # 统计概览（管理权限）
│   │   └── notify/   # 通知列表
│   ├── router/       # 路由配置（路由表 + 守卫）
│   ├── stores/       # Pinia状态管理
│   ├── types/        # TypeScript类型定义
│   └── utils/        # 工具函数
└── vite.config.ts

核心模块划分（按需求）

模块 页面 权限
Skill检索 SearchCenter, Detail 基础
Skill提交 Submit, MySubmissions 基础
审核管理 PendingList, ReviewDetail 审核
系统管理 UserList, DeptList, Permission 管理
统计管理 Overview, Export 管理
通知 List 全部

状态管理（Pinia Stores）

auth (登录状态/Token)
permission (权限列表/菜单)
skill (搜索条件/当前Skill)
notify (未读通知)
